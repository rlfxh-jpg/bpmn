全部放在 extensionElements / 自定义属性里


在 bpmn-js 里添加“自定义节点”，本质上不是随便加一个 DOM，而是要扩展它的 建模能力（Model）+ 渲染能力（Renderer）+ 工具面板（Palette）。你可以理解为三层扩展：

一、核心思路（架构层）

bpmn-js 基于 diagram-js，所有元素都遵循：

Moddle（数据模型）：定义这个节点在 XML 里长啥样
Renderer（渲染器）：定义画出来长啥样
Palette / ContextPad：定义用户怎么创建它

👉 所以“自定义节点 = 三步扩展”

二、步骤详解
1️⃣ 定义自定义类型（Moddle 扩展）

你需要扩展 BPMN 的 XML schema，比如定义一个 custom:MyTask

{
  "name": "Custom",
  "uri": "http://example.com/custom",
  "prefix": "custom",
  "types": [
    {
      "name": "MyTask",
      "superClass": ["bpmn:Task"],
      "properties": [
        {
          "name": "customField",
          "isAttr": true,
          "type": "String"
        }
      ]
    }
  ]
}

初始化时注入：

const modeler = new BpmnJS({
  moddleExtensions: {
    custom: customModdle
  }
});
2️⃣ 自定义渲染（Renderer）

你要告诉 bpmn-js：这个节点长什么样

import BaseRenderer from 'diagram-js/lib/draw/BaseRenderer';

export default class CustomRenderer extends BaseRenderer {
  constructor(eventBus, bpmnRenderer) {
    super(eventBus, 2000); // 优先级高一点
    this.bpmnRenderer = bpmnRenderer;
  }

  canRender(element) {
    return element.type === 'custom:MyTask';
  }

  drawShape(parentNode, element) {
    const shape = this.bpmnRenderer.drawShape(parentNode, {
      ...element,
      type: 'bpmn:Task'
    });

    const rect = document.createElementNS('http://www.w3.org/2000/svg', 'rect');
    rect.setAttribute('width', 100);
    rect.setAttribute('height', 80);
    rect.setAttribute('fill', 'lightblue');

    parentNode.appendChild(rect);

    return shape;
  }
}

注册：

export default {
  __init__: ['customRenderer'],
  customRenderer: ['type', CustomRenderer]
};
3️⃣ 添加到工具栏（Palette）

让用户可以拖出来用：

export default function CustomPaletteProvider(
  palette,
  create,
  elementFactory
) {
  this.getPaletteEntries = function () {
    return {
      'create.custom-task': {
        group: 'activity',
        className: 'bpmn-icon-task',
        title: 'Create Custom Task',
        action: {
          dragstart: createTask,
          click: createTask
        }
      }
    };
  };

  function createTask(event) {
    const shape = elementFactory.createShape({
      type: 'custom:MyTask'
    });

    create.start(event, shape);
  }

  palette.registerProvider(this);
}

四、常见坑（很关键）
⚠️ 1. 只改 Renderer 不够

👉 你会发现导出 XML 不对，因为没扩展 moddle

⚠️ 2. type 必须匹配
element.type === 'custom:MyTask'
⚠️ 3. XML 命名空间问题

必须保证：

xmlns:custom="http://example.com/custom"
⚠️ 4. 优先级问题

Renderer 优先级不够会被默认覆盖：

super(eventBus, 2000);


每个节点“定义独立”，但“注册统一”，运行时按类型分发
